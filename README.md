# 🚀 GDG Workshop • Live Contributors Hub

Welcome to the live interactive React project! Add your profile card to be displayed in real-time during the workshop.

---

### 🌟 How to Contribute (4 Quick Steps):

1. **Fork** this repository to your own GitHub account.
2. Navigate to the folder: `src/data/students/`.
3. Click **Add file** ➡️ **Create new file**.
4. Name the file with your username (e.g., `your-name.json`), and paste the following JSON with your own details:

```json
{
  "name": "Your Full Name",
  "role": "Your Track / Major (e.g., Frontend Dev)",
  "linkedin": "[https://www.linkedin.com/in/your-profile](https://www.linkedin.com/in/your-profile)",
  "github": "[https://github.com/your-username](https://github.com/your-username)",
  "bio": "A short bio about your passions and goals ✨"
}
```

5. Click **Commit changes...** on your new branch, then submit a **Pull Request**!
